# ResortRio

An editorial, Awwwards-caliber digital experience for Resort Rio — a riverside retreat in Arpora, North Goa.

**Live site:** https://www.resortrio.com/

## Development

```sh
git clone <this-repository-url>
cd resortrio
npm i
npm run dev
```

## Stack

- TanStack Start (React 19 + TypeScript)
- Tailwind CSS v4
- GSAP + ScrollTrigger + Lenis (smooth scroll & motion)
- Playfair Display + DM Sans typography
